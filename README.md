# Shockwave Macropad
4x4 KMK macropad with rotary encoder for volume control

## Keymap
- Save, Undo, Redo, Lock
- Play/Pause, Previous/Next, PgUp/PgDn
- Spotify, Chrome, Arrow keys, Enter

## Rotary Encoder
- Turn right → Volume up
- Turn left → Volume down
- Press → Mute/Unmute

## Notes
- Using Seeed XIAO RP2040
- 4x4 key matrix with placeholder GP pins
